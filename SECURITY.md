# Seguridad

## Reportar una vulnerabilidad

No publiques credenciales, datos personales o detalles explotables en un issue público. Contacta al mantenedor por los canales de [kinto.co](https://kinto.co) e indica que el reporte corresponde a Winux Kit.

## Modelo de seguridad

Winux Kit contiene procedimientos que pueden instalar paquetes y modificar configuración de usuario o de sistema. La skill está diseñada para operar con respaldos y autorización visible, pero el usuario sigue siendo responsable de revisar los cambios.

## Recomendaciones

- Descarga Xubuntu únicamente desde su sitio oficial.
- Revisa URLs y repositorios de terceros antes de ejecutar instaladores.
- No pegues contraseñas, tokens o claves en prompts ni archivos del repositorio.
- No ejecutes la personalización sobre una distribución o escritorio no compatible.
- Haz una copia externa de archivos personales antes de instalar el sistema operativo.
- Usa una cuenta sin privilegios para el trabajo diario.

## Alcance

No se consideran vulnerabilidades de Winux Kit los fallos propios de Xubuntu, XFCE o aplicaciones externas; repórtalos a sus proyectos, salvo que esta skill los configure de una forma insegura.
